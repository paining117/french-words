# Study 强化规则更新 · 2026-09-20

**本文为历史规则。** 当前采用 [三颗星强化](three-star-study.md)；以下“两次认识”和模糊词 best-effort 上限已被替换。

用户确认：反复选“不认识”的词允许持续重复；间隔词不足也允许重复；后来选“认识”后还要再强化一次，仍选“认识”才完成。

## 当前行为

- 当前 Session 中一旦选过“不认识”，该词进入必须确认的强化流程，不再受三次出现上限限制。
- 此后只有该词连续两次展示都选“认识”，才移出队列并计入本轮掌握数。中间可以有其他词展示。
- 第一次认识后，下次展示标为“强化确认”。如果又选模糊或不认识，确认重新开始。
- 首次不认识优先在三个其他词展示之后重现；队列不足则放到队尾。后续轮次放队尾，让其他新词和待强化词都有机会展示。
- 只剩一个词时可以直接重复，但仍保留“评分 → 答案 → 继续 → 回忆”的交互。
- 从未选过不认识的词沿用旧规则：认识直接完成；模糊尽量间隔五个其他词展示，最多三次，间隔不足可交给 FSRS。

例：`不认识 × N → 认识（不增加掌握数）→ 强化确认 → 认识（掌握 +1）`。

每次有效评分仍原子保存 FSRS Card 与 Log，唯一新词、每日配额及首次评分统计不会被重复增加。attempt 改为持续递增数字，保证三次之后日志 ID 仍独立；失败重试和连点沿用同一 attempt 的幂等保护。

轮次现在指当天的完整词组。退出后会恢复同一轮的队列、评分后答案页及强化确认状态，详见 [每日轮次与复习清单](daily-study-round.md)。

## 验证与复验

类型检查及 31 项测试通过，涵盖：

- 单个词连续 30 次不认识，仍可继续练习；只有最后确认认识才计入掌握。
- 确认阶段选模糊或不认识，重新要求两次认识。
- 10 个词连续不认识 60 次，所有新词都能出现，且每词超过三次；随后两次认识后全部完成。
- 最终确认失败回滚、重复重试不重复计数；每日累计、午夜及关闭数据库重开回归通过。

手机复验：将最后一个词选“不认识”超过三次，确认仍出现；选一次认识，顶部掌握数不增加；点击继续，看到“强化确认”，再选认识后才增加并完成。
