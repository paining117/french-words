# 开发日期调试

2026-09-20：仅用于 Expo Go / 开发构建。没有新增依赖或数据库表。

## 使用

1. 按原方式双击项目根目录的 `启动法语背单词.cmd`，用 iPhone 相机扫码进入 Expo Go。已打开的 App 可重新加载。
2. 点击主页上方的大号日期，打开“调试日期”。
3. 输入 `YYYY-MM-DD`，例如 `2026-09-21`；也可以点“前一天”或“后一天”。支持 1900–9999 年的有效日期，错误日期会提示且不修改设置。
4. 点击“应用日期”。主页显示“模拟日期”，学习额度和到期复习数立即重新读取。
5. 需要结束模拟时，再次点击日期，选择“恢复真实日期”。

## 日期语义

- 学习额度、当天轮次、首次学习时间、评分日志、FSRS 输入、首次复习 1/3/5 天、签到与总结倒计时统一使用应用时钟。
- 不修改手机系统日期。时分秒继续运行；保存的是相对真实本地日期的日历天偏移，因此跨过午夜会自动进入下一个模拟日，清后台后重开也保留偏移。
- 切换日期只改变“现在”，不会回滚数据库。模拟期间写入的卡片、评分和签到仍然保留；恢复真实日期也不会删除它们。词书累计进度因此不会因日期回退而撤销。
- 返回已学习的日期会加载该日保存的轮次；切到新日期会读取该日额度并从未学词中准备新一轮。
- 待复习数按该时刻所有未暂停且到期的卡片计算，包含之前日期积累的到期词，不仅是当天新到期的词。当前 Review 页面仍为原有占位，本次不新增正式复习答题流程。

## 实现与发布限制

应用时钟入口为 `src/utils/appClock.ts`；纯日历偏移在 `clockCore.ts`。仅开发环境加载 `src/components/dev/DebugDateDialog.tsx` 和 `src/services/dev/debugDateService.ts`。设置保存在 SQLite `settings.dev_date_offset_days`，写入成功后才通知首页更新；数据库初始化在计算学习日之前恢复设置。

正式环境通过 `__DEV__` 移除弹窗加载和日期按钮，并且时钟自身拒绝修改，即使数据库残留开发设置也只使用真实时间。**这是开发期间的保护；用户还要求正式发布前从源码删除功能，必须完成 [发布清单](release-checklist.md)。**

iOS 开发 JS 包和 iOS / Android 正式 JS 包均编译通过。开发包包含日期弹窗、设置键及日期按钮；两平台正式 JS 包中均未发现 `FRENCH_WORDS_DEV_DATE_DIALOG`、`dev_date_offset_days`、日期按钮及主页调试提示。为方便检查字符串，这次使用 `--no-bytecode` 导出；这不是商店安装包或真机触摸验收。

真机仍需检查：

- 日期点击、输入框和键盘不遮挡按钮，“取消”不生效输入内容。
- 学完一轮后向后切换 1、3、5 天，核对到期词数；再返回原日期，核对整组总结。
- 中途退出并清后台重开，模拟日期及当天已学数量保留。
- 恢复真实日期后，主页日期与 iPhone 系统日期一致。
- 正式发布包无日期按钮/调试提示，详见发布清单。
