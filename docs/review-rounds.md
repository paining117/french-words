# 20 词复习与名词冠词

## 当前规则

- 名词冠词仅在详情中显示：学习／复习答题后的详情与查词详情，在单词下方单独一行以 14 号小字显示词库提供的 `le` 或 `la`。非名词或性别未知不显示。
- 题目、答错后的选项标签、查词候选／历史、学习／复习总结只显示原始单词；查词匹配、词条 ID 和保存的 lemma 不变。已有选项数据中的 frenchLabel 保留兼容，但不再用于界面。
- 四选一布局参考用户截图，单词靠上左对齐，四个选项加宽加高放在中下部，中间用弹性留白。选项高度随屏幕调整，底部预留反馈继续按钮空间；长文本／大字号允许滚动。
- 四个中文选项取消前置 A/B/C/D，保留选对变绿自动进入详情、选错变红后手动继续。
- 每轮复习先读取全局到期卡片并按遗忘风险排序，再取最多 20 个不同词。首页到期数仍是全局真实数量。
- 首次选对直接掌握；首次选错后走三步强化。重复练习不占新名额、不重复更新 FSRS 或统计。
- 全部掌握后，总结只显示本轮词条、主要中文释义、距下次复习的天数（当天显示“今天复习”，已到期显示“待复习”），不显示具体时间。页底显示今日正式复习次数，提供继续复习和返回首页。
- 继续复习重新读取到期词；不足 20 个按实际数量，没有待复习则显示空状态。若之前答错的词按 FSRS 已再次到期，也会再次进入候选。
- Review 队列仍不跨退出持久化，已评分卡片与日志即时保存；重新进入以当时真实 due 创建新轮。学习轮次仍持久化，不改变原有规则。
