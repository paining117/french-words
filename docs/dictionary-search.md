# 英文键盘与实时查词

2026-09-20：本地查词升级，无新增依赖，无数据库迁移。

## 使用方式

在主页任意内容位置向下拉后松手进入独立查词页（也可点击底部“下拉查词”）。页面使用与学习页相同的主页模糊背景，输入框固定在顶部安全区域，进入后自动聚焦键盘。输入框最右侧的线框放大镜和键盘搜索键均可提交查询。

入场改为约 260 毫秒淡入，内容从上方向下轻移 28 点，不再从右侧滑入。从单词详情返回不重复播放入场；系统开启减少动态效果时取消内容位移。入场淡入与原生水平返回手势分开配置，仍支持向右滑返回及中途取消。

停止输入约 180 毫秒后自动显示候选；每行包含原始法语拼写、词性/阴阳性和主要中文意思。点击候选进入单词详情页，查看完整释义和例句。空输入时直接展示查询历史，历史同样显示单词、词性与释义。去掉所有查词标题、介绍、副标题、方向切换、词库提示、候选数量及历史标题。

iPhone 查词页使用原生导航栈的水平返回手势：手指向右滑动返回主页，支持全屏触发和交互动画；Android 保留系统返回。主页下拉手势只在松手且纵向移动至少 64 点时打开查词，短距离拖动和左右滑不打开，轻点按钮仍可操作。调试日期弹窗打开时不触发下拉入口。

| 输入 | 示例结果 |
| --- | --- |
| `ecole` / `eco` / `cole` | école |
| `etudiant` | étudiant |
| `soeur` / `une soeur` | sœur / une sœur |
| `cafe` | café |
| `etre` | être |
| 汽车 | voiture |

支持法语重音省略、`ç → c`、`œ → oe`、`æ → ae`、大小写、组合重音，以及直/弯撇号兼容。只有实际存在于本地词库的词才会显示。本次模糊匹配指前缀或连续片段匹配，不包含任意错别字纠正或在线扩展词典。

排序为原拼写完全匹配、显示形式完全匹配、忽略重音/连字后的完全匹配、前缀、包含片段。最多显示 20 个候选，继续输入可缩小范围。中法方向自动识别，不再显示方向控件。

输入过程只读数据库；点击候选记录具体词条，提交搜索且结果唯一（或只有一个精确匹配）时也记录具体词条。用现有历史表的文本主键 `entry:<wordId>` 保存词条身份，不改变数据库结构，同拼写不同词性可分别保留。读历史时查询词条的实际词性及释义；旧版本的输入历史仅在能唯一精确匹配时展示，歧义片段及已删除词不冒充确定词条，原始历史数据仍保留。重复词条只显示一次，最近 20 条保留。

清空输入后恢复历史列表。输入片段不会逐个填满历史，较早请求的结果/错误不会覆盖较新输入；退出组件会取消待执行查询。

## 数据与性能边界

搜索折叠仅用于匹配，原 `normalizeFrench`、词条 ID 和去重规则不变。例如 `ou` / `où` 不会合并，已有学习卡片和复习记录保留。

当前为 66 词的本地示例词库，法语候选读取词表后在 JavaScript 中折叠和排序，无需修改旧设备数据库。候选仅读主释义；选择后由详情页读取完整释义及例句。接入大规模正式词库时，应增加持久化搜索字段/索引并进行性能测试，避免每次全表读取。
