# 复习三步与四选一反馈

2026-09-21。适用于新词学习和正式复习，覆盖 Phase 3 最初的单次展示流程。

## 学习与复习

学习保持三颗星：四选一正确加第一颗，看中文选认识加第二颗，看法语选认识加第三颗。任一步失败清零，从四选一开始。

复习使用相同题型，但首次四选一正确直接掌握并显示三颗星；首次错误保持 0 星，稍后从四选一开始完成三步。未掌握的词按现有学习队列规则稍后出现，队尾不足间隔时仍允许重复；失败可不限次数重练。进入时的词组与分母固定，新到期词不会插入。

学习与复习第一题都只提供四个中文选项，不显示底部模糊／不认识。第二、第三题保留认识／不认识。

## 选择反馈

- 提交成功后才显示颜色；保存失败保留原题，可重试。
- 正确：仅所选项绿框，停留约 700 毫秒，自动进入当前目标词的详情。
- 错误：所选项红框，所有中文选项旁显示各自对应的法语词；不会自动离开。点底部“继续”查看正确目标词详情，不打开干扰词详情。
- 详情沿用 WordAnswer，包含目标法语词、词性、释义及例句；详情中的继续才进入下一题。
- 选择后锁定四个选项，反馈和详情显示不再写评分。语音辅助标签可读出选中项正确／错误，界面不添加提示文案。
- 反馈保留题目滚动位置，切换详情时回到顶部；离开页面或切后台取消自动跳转，回到前台重新等待。
- 原有学习轮次缺少选项法语词时从词库补齐，保持选项顺序、星数、选中结果、Card 与日志。

## 复习调度与保存

每个词第一次评分仍是一次正式 Review：复用原 FSRS wrapper、事务和日志。其后的三步只用于本轮掌握，不再次增加 FSRS reps、Log 或今日／累计正式复习次数，也不会把第一次失败的 due 推远。复习总结仍统计各词首次回答；顶部计数统计实际掌握数量，只有首次正确或第三颗星完成才增加。

保留此前的 Review 中断规则：正式评分即时持久化，当前 Review 队列和练习星数存在内存中。退出后重新进入会根据 due 建立新快照，当前未完成的复习练习不会恢复。Study 仍完整保存轮次、星数与选择结果，清后台后可继续。

没有新增依赖或数据库表。`MeaningChoice` 补充法语 lemma；复用 `prepareMeaningChoices`、`advanceStudyQueue`、`ReinforcementPrompt`，学习与复习共用 `useChoiceFeedback`。
